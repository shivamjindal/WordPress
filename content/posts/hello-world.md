Welcome to **RustPress**, a tiny Rust implementation of a WordPress-like blog.

This sample post proves the Rust server can load content from disk, render Markdown to HTML, and serve it with a simple theme.

## What’s next?

- Add more posts in `content/posts/`
- Customize `content/site.toml`
- Tweak styling in `static/styles.css`
